# LevelUpPvp

![LevelUpPvp cover](assets/cover.png)

一个 AstrBot 群聊养成 PVP 插件：签到获取经验，升级获得随机属性成长和自定义属性点，再通过 At 群友发起带策略的概率战斗。

## 功能

- 群内每天第一条消息自动签到，任意消息类型均可触发
- 每级抽取一次 1 到 100 经验，低于升级需求 10% 时改为 8% 到 12% 随机经验
- 签到基础经验最多为本级升级需求的 60%
- 连续签到提供额外随机加成
- 指数经验曲线升级
- 升级时随机提升若干不重复属性
- 自定义属性点加点，每点独立随机提升
- At 用户发起 PVP 挑战
- 根据属性克制、等级、幸运、攻防双方策略计算胜率
- 内置 18 种战斗策略；未填写策略时攻防双方都会随机选择
- 自定义战斗策略会保留原文，并按 3 个核心属性参与判定
- LLM 可用时生成胜率分析，不可用时自动使用本地规则
- SQLite 持久化用户、签到、升级、加点、战斗记录

## 指令

```text
/签到
/面板
/面板 @用户
/加点 攻击 2
/排行
/排行 @用户
/登记 昵称
/修改登记 @用户 昵称
/挑战 @用户 防守反击
@机器人 签到
@机器人 面板 @用户
@机器人 加点 攻击 2
@机器人 排行
@机器人 登记 昵称
@机器人 修改登记 @用户 昵称
@机器人 挑战 @用户 防守反击
@用户 艾斯比 防守反击
```

## 属性

- 生命：提高容错和持久战能力
- 攻击：提高压制和终结能力
- 防御：提高抗爆发能力
- 速度：影响先手、闪避和节奏
- 幸运：影响暴击、反转和爆冷概率

## 说明

群成员无需登记即可通过每天第一条群消息或 `/签到` 获取签到经验。普通群消息仅在当天首次签到成功时回复；再次发送 `/签到` 可查询今日获得经验、连续签到天数和当前等级信息。
签到日按服务器本地时间每天早上 05:00 重置；00:00–04:59 仍计入前一天。


除 `/签到` 和 `/登记 昵称` 外，所有插件指令都需要先完成昵称登记后才能使用。

签到时会按当前等级抽取相同次数的 `1–100` 随机经验。若总和低于本级升级需求的 10%，则直接改为需求的随机 8%–12%；基础奖励封顶为需求的 60%，连续签到奖励在封顶后额外计算。

`/修改登记 @用户 昵称` 仅 AstrBot 管理员可用，用于修改指定用户的昵称映射。

战斗限制为 10 分钟内最多主动挑战别人 3 次。被别人挑战后，可以在 2 分钟内免费反击刚刚挑战你的人 1 次；免费反击不消耗主动挑战次数，且不会让被反击的人获得新的免费反击。

挑战成功后的战报会根据平台自动选择发送方式：QQ Official（含 Webhook）发送为图片，OneBot（aiocqhttp）发送为折叠的合并转发消息，其他平台发送为普通文本。

战斗不是单纯比较战力。插件会先评估胜率，再随机判定结果；高胜率不代表必胜，低胜率也有机会爆冷。策略克制需要对应属性支撑，例如奇袭、先手、拉扯类策略要求速度条件，条件不足会在概率上受到反噬。

当前内置策略：稳扎稳打、全力猛攻、防守反击、游走消耗、先手压制、诱敌深入、持久消耗、奇袭爆发、以守为攻、速度拉扯、幸运赌局、破防强攻、闪避拖延、控制节奏、血量压制、精准打击、扰乱节奏、背水一战。

第一版暂不包含战斗记录查询命令，但底层数据已经持久化，后续可继续扩展。
