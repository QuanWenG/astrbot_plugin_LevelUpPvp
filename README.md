# LevelUpPvp

![LevelUpPvp cover](assets/cover.png)

一个 AstrBot 群聊养成 PVP 插件：签到获取经验，升级获得随机属性成长和自定义属性点，再通过 At 群友发起带策略的概率战斗。

## 功能

- 每日签到获得随机经验
- 连续签到提供额外随机加成
- 指数经验曲线升级
- 升级时随机提升若干不重复属性
- 自定义属性点加点，每点独立随机提升
- At 用户发起 PVP 挑战
- 根据属性克制、等级、幸运、策略计算胜率
- LLM 可用时生成胜率分析，不可用时自动使用本地规则
- SQLite 持久化用户、签到、升级、加点、战斗记录

## 指令

```text
/签到
/面板
/面板 @用户
/加点 攻击 2
/挑战 @用户 稳扎稳打，等待反击
```

## 属性

- 生命：提高容错和持久战能力
- 攻击：提高压制和终结能力
- 防御：提高抗爆发能力
- 速度：影响先手、闪避和节奏
- 幸运：影响暴击、反转和爆冷概率

## 说明

战斗不是单纯比较战力。插件会先评估胜率，再随机判定结果；高胜率不代表必胜，低胜率也有机会爆冷。

第一版暂不包含排行榜和战斗记录查询命令，但底层数据已经持久化，后续可继续扩展。
